Different lenders, different forms

Each lender uses a different application format and returns its decision differently. A partner has to handle those differences even when its customer fills in a single form.

One API for partners

I launched Ping3 with a single partner API. It translates applications into the format each lender requires and returns approved offers in a common format. Partners display them in their own interfaces. Lenders report a funded loan as a separate event.

How does a partner distinguish an offer from a funded loan?

First the lender returns an offer. Once the loan is funded, the lender sends a separate notification. The platform can then match the funded loan to the original application.
