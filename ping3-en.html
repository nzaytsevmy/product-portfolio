A partner submits the application once. Ping3 adapts it to each lender’s format and receives funding status separately.

Different lenders, different forms

Each lender uses a different application format and returns its decision differently. A partner has to handle those differences even when its customer fills in a single form.

One API for partners

I launched Ping3 with a single partner API. It translates applications into the format each lender requires and returns approved offers in a common format. Partners display them in their own interfaces. Lenders report a funded loan as a separate event.

How does a partner distinguish an offer from a funded loan?

First the lender returns an offer. Once the loan is funded, the lender sends a separate notification. The platform can then match the funded loan to the original application.

Payments at MVP Group

I chose a payment provider using A/B test results, then improved acquiring, token handling and card linking. Over six months, the share of paying users among users with a linked card rose from 2.1% to 5.4%, a gain of 3.3 percentage points.

Offer ranking at MVP Group

I configured, trained and integrated CatBoost to rank lender offers. The model reached an AUC above 0.90. I refined it over three months and retrained it for seasonality. The lender makes each credit decision.

Product analysis

When another lender adds funded loans

Where to look for impact

I’d measure the share of distinct applications that produce at least one confirmed funded loan within the same follow-up window. One application can generate several requests and offers. Linking events back to the original application lets me count it once and identify the lender that approved and funded the loan.

How to test a lender’s contribution

For applications eligible for the new lender, I’d compare randomly assigned groups using the existing lender pool and the expanded pool. A sustained lift in the funded-application rate for the expanded pool would support rolling out the integration. If loans simply shift between lenders, I’d weigh the cost of maintaining the integration. I’d also compare time to first offer and the completeness of funding notifications.
